 Hotel Reservation System Using MySQL

Project Overview
The Hotel Reservation System is a database management project developed using MySQL. It manages hotel details, customer information, room details, reservations, and payment records.

 ## Objectives
- Store customer information.
- Manage hotel rooms and room availability.
- Maintain reservation records.
- Track customer payments.
- Generate booking and revenue reports.

 ## Features
- Customer management
- Hotel and room management
- Room availability checking
- Reservation management
- Payment tracking
- Booking reports

 ## Technology Stack
- Database: MySQL
- SQL Editor: MySQL Workbench

## Database Tables
1. Hotel
2. Customer
3. Room
4. Reservation
5. Payment

## SQL Concepts Used
- DDL and DML
- Primary and Foreign Keys
- Constraints
- Joins
- Aggregate Functions
- GROUP BY and ORDER BY
- Subqueries
- Views
- Transactions

## How to Run
1. Install MySQL Server and MySQL Workbench.
2. Download or clone this repository.
3. Open the SQL file in MySQL Workbench.
4. Execute the SQL statements.
5. Run the queries to view the results.

## Conclusion
This project demonstrates how MySQL can be used to manage hotel reservations efficiently through relational database concepts and SQL queries.
