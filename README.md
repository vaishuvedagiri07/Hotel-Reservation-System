# Hotel Reservation System

## About the Project
This project is based on a Hotel Reservation System developed using MySQL. The main idea is to maintain hotel details, customer information, room details and booking records in a database.

Instead of maintaining all the details manually, this database helps to store and retrieve information using SQL queries.

## What does this project do?
- Stores customer details.
- Maintains hotel and room information.
- Keeps track of room bookings.
- Stores payment details.
- Helps to check room availability.
- Displays reservation details whenever required.

## Database Design

The project contains the following tables:

| Table Name | Description |
|---|---|
| Hotel | Stores hotel information |
| Customer | Stores customer details |
| Room | Contains room numbers, types and prices |
| Reservation | Maintains booking information |
| Payment | Stores payment records |
